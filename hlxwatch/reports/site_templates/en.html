What is HLX?

It is a code name that shows up in the public files of Valve's games: Counter-Strike 2, Dota 2, Deadlock and others. Valve has never said what it is. The most common theory is that it is a new Half-Life, not in virtual reality: Valve names its games with short tags like this. Half-Life: Alyx, for example, is called hlvr in its files.

Nobody knows. The dates going around (anniversaries, events, "this year") are rumours, and none of them has come true so far. The game files show that Valve is working on it, not when it will be done.

How can anyone know, if Valve says nothing?

Every game update on Steam ships public files: text strings, Source 2 engine class names, resource lists. The SteamTracking project archives them on GitHub. When Valve shares code between its games, names from the HLX project end up in those files too, such as classes starting with CHLX.

HLX Watch reads this public data, scores every line and sends alerts. It uses no accounts, private files or leaked data.

How do I get notified right away?

  • Notifications on your computer or phone: the "Attiva notifiche" (turn on notifications) button at the top.
  • Android app with an alarm for possible announcements: download the APK.
